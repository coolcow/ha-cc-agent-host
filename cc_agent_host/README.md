# CC Agent Host

Runs the official, unmodified Claude Code CLI inside Home Assistant with your own Claude subscription.

Claude Code works directly in your Home Assistant configuration: it sees the real files and logs, writes
and fixes YAML, and explains why an automation did not fire. No copying YAML into a chat window, no
syncing your configuration to another computer, and every change needs your approval.

- **Web terminal** in the Home Assistant sidebar, on any device.
- **Remote Control** (optional): continue from claude.ai/code or the Claude app on your phone.
- **Jobs from automations** with the companion integration: ask Claude Code a question on a schedule
  (for example a morning digest of new errors), sandboxed and read-only.
- **Sensors** for sign-in state and plan usage, and Claude Code updates under Settings → Updates.

Requirements: 64-bit Home Assistant OS (aarch64 or amd64), 2 GB RAM or more, a Claude
Pro or Max subscription. See the **Documentation** tab for setup and details.
